# 5.3 Integration Test Plan and Report

**Project:** InternLink Uganda · **WBS:** 5.3 Integration testing · **Owner:** Aryatusinguza Arthur
**Status:** Executed 30 Oct 2026 for the parts that exist; the rest is blocked (Section 6)

## 1. Scope

WBS 5.3 asks for two end-to-end flows to be tested across components:

- **Flow A, application → shortlisting:** a student applies, the employer reviews and shortlists, and both sides are notified.
- **Flow B, approval → completion:** an accepted application becomes a placement, which the university approves or rejects, then monitors with check-ins; the employer completes it.

It also covers the integration of the **matching engine** with the database and API (4.6).
